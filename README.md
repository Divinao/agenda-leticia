# Agenda da Letícia

Agenda de tarefas para Windows, organizada por blocos (Prazo de processo aberto, Processos ativos, Pessoais, Médicos, Administração, Assessorias, Aluguéis e renovações), com calendário e lembretes.

## Baixar

**[Clique aqui para baixar a versão mais recente](https://github.com/Divinao/agenda-leticia/releases/latest/download/Agenda-da-Leticia.exe)**

1. Salve o arquivo na Área de Trabalho ou em Documentos e dê dois cliques para abrir.
2. Se aparecer *"O Windows protegeu o computador"*, clique em **Mais informações** e depois em **Executar assim mesmo** (só na primeira vez).

## Atualizações

Não é preciso baixar de novo: quando houver uma versão nova, a própria agenda mostra **"Atualizar agora"**. As tarefas são mantidas.

## Privacidade

As tarefas ficam salvas apenas no computador onde a agenda é usada. Nada é enviado para este site.
